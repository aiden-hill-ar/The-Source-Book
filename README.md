# The Source Book

## What is it?

The source book is a personal project where I write a little about some of the developers who I have researched, been inspired by, and learned from. 

I've made The Source Book as a reference for me so I can have a single place for my people, but it's also available for others to discover a handpicked curation of people who have great ideas.

## Why was it made?

To organize the people I know and for others to easily find and learn something new.

# Important

**The Source Book is *not* finished.**

I am working on it in my free time while managing school and other hobbies, but I guess you didn't expect much from a personal project to begin with.
